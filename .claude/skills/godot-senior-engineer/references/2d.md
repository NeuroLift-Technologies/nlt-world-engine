# 2D

## Core nodes
- Bodies:
  - `CharacterBody2D` for player and NPC control: set `velocity`, then call `move_and_slide()`. Choose `motion_mode` `GROUNDED` (platformers) or `FLOATING` (top-down).
  - `RigidBody2D` for simulated objects.
  - `StaticBody2D` / `AnimatableBody2D` for moving platforms. `AnimatableBody2D` with `sync_to_physics` carries riders correctly.
  - `Area2D` for triggers, hitboxes, pickups and detection.
- Platformer feel: tune `floor_snap_length`, `floor_max_angle` and `floor_constant_speed`. Make coyote time and jump buffering explicit timers in your code; they aren't engine features.
- One-way platforms: the `one_way_collision` property on `CollisionShape2D`/`CollisionPolygon2D`, with a margin. 4.7 extended one-way collision support, so check the docs for the project's version.

## Tiles
- Use **`TileMapLayer`** (4.3+), one node per layer. `TileMap` is deprecated; migrate with the editor's "Extract TileMap layers as individual TileMapLayer nodes".
- A `TileSet` holds atlases, physics layers, navigation layers, custom data layers and terrains. Use terrain sets (match corners/sides) for autotiling.
- Custom data layers (for example `is_hazard`, `footstep_sound`) are the clean way to attach gameplay data to tiles. Read them with `get_cell_tile_data(coords).get_custom_data("name")`.
- Since 4.5, tile physics is chunked, so large maps no longer make one body per tile. Still avoid huge maps of physics tiles you don't need.
- Scene tiles (`TileSetScenesCollectionSource`) place full scenes as tiles. They're useful for interactables, but each one is a real node, so don't use them to paint thousands.

## Rendering and organization
- Draw order: tree order, then `z_index`, then `CanvasLayer` layers. Use `y_sort_enabled` on a parent (and on the TileMapLayer) for top-down depth. Each sprite's sort point is its origin, so put the origin at the feet.
- `CanvasLayer` for HUD and UI that ignores the camera. `CanvasModulate` for global tint, with `PointLight2D`/`DirectionalLight2D` and `LightOccluder2D` for 2D lighting.
- `Parallax2D` (4.3+) replaces ParallaxBackground/ParallaxLayer. It handles scroll scale, repeat size and autoscroll.
- `Camera2D`: `position_smoothing`, limits, and `drag` margins. For screen shake, offset the camera with noise rather than moving the node.
- Pixel art:
  - Set `rendering/textures/canvas_textures/default_texture_filter` to Nearest.
  - Use the stretch mode `viewport` (or `canvas_items` with integer scaling) and an integer `stretch/scale_mode`.
  - Enable `snap_2d_transforms_to_pixel` / `snap_2d_vertices_to_pixel` if sprites shimmer.
- Many identical moving sprites: `MultiMeshInstance2D`, or `GPUParticles2D`/`CPUParticles2D` for effects.

## Animation in 2D
- `AnimatedSprite2D` + `SpriteFrames` for frame-based animation.
- `AnimationPlayer` when you also animate properties, hitboxes or calls.
- `Skeleton2D`/`Bone2D` + `Polygon2D` for cutout rigs.
