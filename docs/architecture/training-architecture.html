UE5 Side — What Runs Every Tick (0.1s)

NLTTrainingManager::Tick() — orchestrates everything
→ LTCognitiveStateComponent::TickCognitiveDecay() — cognitive decay/growth
→ NLTAvatarInteractor::GatherAgentObservation() — 13-dim obs
→ ULearningAgentsPPOTrainer::RunTraining() (every 1.0s)
→ NLTTrainingEnvironment::GatherAgentReward()
→ NLTEpisodeManager::CheckCognitiveCompletion() — independence/burnout/step cap
ADHD note: The 0.1s tick interval mirrors the rapid pacing of ADHD cognition — thoughts, impulses, and state changes happen fast. This is why stress can spike and decay quickly between interventions.

Python Side — PPO Orchestrator

File: neurolift-ai-fusion/src/simulation/training/train_nlt.py

1. Connect to UE5 shared memory communicator (port 5555)
2. Receive observations (13-dim float × 2 agents per pair)
3. Evaluate policy networks → get action probabilities
4. Sample actions → send back (3 continuous + 4 discrete for Avatar, 10 discrete for Aide)
5. Receive rewards (computed by NLTTrainingEnvironment::GatherAgentReward)
6. PPO update step (clip ε=0.2, λ=0.95, γ=0.99)
7. Log scalars → TensorBoard

Reward Function

GatherAgentReward in NLTTrainingEnvironment.cpp:

reward = +1.0 * Independence
       − 1.0 * Burnout
       − 0.5 * Stress
       + 0.3 * Focus
       + 0.5 * SuccessRate

Episode Completion Logic

NLTEpisodeManager::CheckCognitiveCompletion:

ConditionResultReason
Independence ≥ 0.8SuccessAvatar learned to work independently

ADHD insight: Independence is the goal — not speed, not perfection. The reward function rewards the Avatar for needing less help, which mirrors the real ADHD journey of building self-advocacy and self-management skills.
